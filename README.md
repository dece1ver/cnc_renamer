# CNC Remedy

Инструмент для работы с файлами управляющих программ ЧПУ через контекстное меню проводника (либо CLI).

## Возможности

- **Переименовать УП** - переименовывает файл по названию программы внутри него
- **Архивировать УП** - перемещает файл в папку `_/дата/` рядом с ним
- **Очистить комментарии** - удаляет строки комментариев из УП
- **Сформировать таблицу инструментов** - автоматически создаёт таблицу инструментов на основе содержимого УП
- **NC Tool Table (`cnctt`)** - читает УП из окна CIMCO Edit или файла и копирует список инструментов в буфер обмена

Все команды группируются в подменю **CNC Remedy** при установке. В контекстном меню фона (`Directory\Background`) команды размещаются без подменю - напрямую.

## Поддерживаемые СЧПУ

| СЧПУ | Формат имени | Расширения |
|------|-------------|------------|
| Fanuc 0i | `O0001(НАЗВАНИЕ)` | `.nc`, `.cnc`, ... |
| Fanuc 0i-\*F | `<НАЗВАНИЕ>` | `.nc`, `.cnc`, ... |
| Mazatrol Smart | Имя по смещению (байт 80, 32 символа) | `.pbg`, `.pbd` |
| Sinumerik 840D sl | `MSG("НАЗВАНИЕ")` | `.mpf`, `.spf` |
| Heidenhain | `BEGIN PGM НАЗВАНИЕ MM` | `.h` |

## Конфигурация

Файл `%ProgramData%\dece1ver\CNC Remedy\cncr.toml`. Параметры команд задаются в секции `extra`:

- `cncr --reset-config` - сброс конфигурации на умолчания
- В интерактивном меню: `[3] Настройки` → `[d] Сбросить настройки по умолчанию`

### Переименовать

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `prefix` | Добавляется в начало имени файла | (пусто) |
| `suffix` | Добавляется в конец имени (до расширения) | (пусто) |
| `overwrite` | При конфликте имён оставляет новейший файл | `false` |
| `recurse` | Рекурсивный обход поддиректорий (background) | `false` |

### Архивировать

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `date_format` | Формат даты подпапки (`%d%m%y.%H%M`) | `%d%m%y.%H%M` |
| `timestamp_source` | `now` - текущее время, `modified` - дата изменения файла | `now` |

### Очистить комментарии

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `keep_string` | Фрагменты через запятую; строки с ними не удаляются | `MSG` |
| `comment_chars` | Символы комментария | `;` |
| `strip_mode` | `starts-with` / `contains` (где искать символ комментария) | `starts-with` |

### Сгенерировать таблицу инструментов

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `fanuc_milling_line` | Номер строки для вставки таблицы (Fanuc Milling) | `6` |
| `fanuc_lathe_line` | Номер строки для вставки таблицы (Fanuc Lathe) | `6` |
| `sinumerik_line` | Номер строки для вставки таблицы (Sinumerik) | `6` |
| `heidenhain_line` | Номер строки для вставки таблицы (Heidenhain) | `3` |
| `fanuc_milling_print_tool_number` | Выводить T/H/D (Fanuc Milling) | `true` |
| `fanuc_lathe_print_tool_number` | Выводить T (Fanuc Lathe) | `true` |
| `sinumerik_print_tool_number` | Выводить T (Sinumerik) | `true` |
| `heidenhain_print_tool_number` | Выводить T (Heidenhain) | `true` |

Форматы вставляемой таблицы (при `print_tool_number = true`):

- **Fanuc Milling:** `(T01 H01 D01 - 10MM ENDMILL)`
- **Fanuc Lathe:** `(T0101 - ROUGH TURN)`
- **Sinumerik / Heidenhain:** `;T01 - 10MM ENDMILL`

При `print_tool_number = false` выводится только комментарий:

- **Fanuc Milling:** `(10MM ENDMILL)`
- **Fanuc Lathe:** `(ROUGH TURN)`
- **Sinumerik / Heidenhain:** `;10MM ENDMILL`

## NC Tool Table (`cnctt`)

Отдельный исполняемый файл (замена NCToolTable из репозитория Utils): таблица инструментов из УП сразу в буфер обмена.

| Режим | Описание |
|-------|----------|
| `cnctt` | Находит активное окно CIMCO Edit → таблица в буфер обмена |
| `cnctt <файл>` | Таблица из указанного файла |
| `cnctt --no-numbers` | Только комментарии, без номеров инструментов |
| `cnctt --help` / `-h` | Показать справку |

Поддержка кодировок файлов: UTF-8/UTF-16 (BOM) и CP1251.

### CLI

| Команда | Описание |
|---------|----------|
| `cncr <команда> <файлы...>` | Запустить команду для указанных файлов |
| `cncr install` | Установить программу (администратор) |
| `cncr uninstall` | Удалить программу (администратор) |
| `cncr --reset-config` | Сбросить настройки на умолчания |
| `cncr` (без аргументов) | Интерактивное TUI-меню |

Команды: `rename`, `archive`, `strip-comments`, `generate-tool-list`.

## Установка

Требуются права администратора.

```
cargo install --git https://github.com/dece1ver/cnc_remedy.git
```
или скачать из релизов.

Выполнить `cncr install` или запустить `cncr.exe` и нажать `[1]` в меню. 
Программа:
1. Копирует себя в `C:\Program Files\dece1ver\CNC Remedy`
2. Добавляет подменю **CNC Remedy** в контекстное меню (`*`, `Directory`, `Directory\Background`)
3. Прописывает путь в системную переменную PATH
