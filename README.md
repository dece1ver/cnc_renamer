# CNC Remedy

Инструмент для работы с файлами управляющих программ ЧПУ через контекстное меню проводника.

## Возможности

- **Переименовать УП** — переименовывает файл по названию программы внутри него (prefix/suffix/overwrite/recurse)
- **Архивировать УП** — перемещает файл в папку `_` рядом с ним (формат даты и источник времени настраиваются)
- **Очистить комментарии** — удаляет строки комментариев (символы и keep_string настраиваются)
Все команды группируются в подменю **CNC Remedy** при установке.

## Команды

### `rename` — Переименовать УП
Переименовывает файл по названию программы внутри него.

### `archive` — Архивировать УП
Перемещает файл в папку `_` рядом с ним, в подпапку с датой.

### `strip-comments` — Очистить комментарии
Удаляет строки комментариев, кроме содержащих заданные фрагменты.

## Поддерживаемые СЧПУ

| СЧПУ | Формат |
|------|--------|
| Fanuc 0i | `O0001(НАЗВАНИЕ)` |
| Fanuc 0i-\*F | `<НАЗВАНИЕ>` |
| Mazatrol Smart | `.PBG` / `.PBD` |
| Sinumerik 840D sl | `MSG("НАЗВАНИЕ")` |
| Heidenhain | `BEGIN PGM НАЗВАНИЕ MM` |

## Конфигурация

Файл `%ProgramData%\dece1ver\CNC Remedy\cncr.toml`. Параметры команд задаются в секции `extra`:

- `cncr --reset-config` — сброс конфигурации на умолчания
- В интерактивном меню: `[3] Настройки` → `[d] Сбросить настройки по умолчанию`

### Переименовать (`rename`)

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `prefix` | Добавляется в начало имени файла | (пусто) |
| `suffix` | Добавляется в конец имени (до расширения) | (пусто) |
| `overwrite` | При конфликте имён оставляет новейший файл | `false` |
| `recurse` | Рекурсивный обход поддиректорий (background) | `false` |

### Архивировать (`archive`)

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `date_format` | Формат даты подпапки (`%d%m%y.%H%M`) | `%d%m%y.%H%M` |
| `timestamp_source` | `now` — текущее время, `modified` — дата изменения файла | `now` |

### Очистить комментарии (`strip-comments`)

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `keep_string` | Фрагменты через запятую; строки с ними не удаляются | `MSG` |
| `comment_chars` | Символы комментария | `;` |
| `strip_mode` | `starts-with` / `contains` (где искать символ) | `starts-with` |

### CLI

| Команда | Описание |
|---------|----------|
| `cncr <команда> <файлы...>` | Запустить команду для указанных файлов |
| `cncr install` | Установить программу (администратор) |
| `cncr uninstall` | Удалить программу (администратор) |
| `cncr --reset-config` | Сбросить настройки на умолчания |
| `cncr` (без аргументов) | Интерактивное TUI-меню |

Команды: `rename`, `archive`, `strip-comments`.

## Установка

Требуются права администратора.

```
cargo install --git https://github.com/dece1ver/cnc_remedy.git
```

Либо выполнить `cncr install` или запустить `cncr.exe` и нажать `[1]` в меню. Программа:
1. Копирует себя в `C:\Program Files\dece1ver\CNC Remedy`
2. Добавляет подменю **CNC Remedy** в контекстное меню
3. Прописывает путь в PATH
